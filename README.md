# 加班统计

简洁的个人加班工时统计 Android App，开发者 **π**。支持 Android 8.0 及以上。

## 下载

前往 [Releases](https://github.com/lyz10-26/OvertimeStats/releases) 下载 `Overtime-1.3.1.apk`。

## 功能

- **钉钉通知采集**：授权通知使用权后，识别系统通知中的打卡成功结果；信息不完整或时间冲突时人工确认。
- **工作日加班**：08:30～09:00 弹性上班，对应18:00～18:30下班；正常下班后30分钟起算，间隔可设置。
- **周末 / 休息日**：上下班打卡间隔扣除1小时，不足1小时按0计算；调休可切换为工作日规则。
- **工时记录**：今日预计/已确认加班、历史月统计、工作日与休息日分类、缺卡补录和修正。
- **界面**：黑白灰主题，今日、统计、设置三个入口，无广告、无第三方统计。

## 1.3.1修复

适配实际通知“考勤打卡：19:09 下班打卡·成功”：正文没有日期时，可信考勤来源、非凌晨且通知与打卡时间相差0～10分钟，可按系统通知发布时间推定日期，并在详情标明依据。打卡时间仍取正文，不使用送达时间代替。

- 使用通知原始发布时间，不使用App处理时间；重新连接时可读取仍留在通知栏的考勤通知。
- 凌晨、补卡、历史描述、日期冲突及异常延迟进入待确认。
- 通知页新增“重新识别待确认消息”，以原采集时间重新处理已保存的旧格式通知。
- 无法恢复已经消失且此前未采集的消息；原周末扣1小时规则保留。

## 使用

1. 安装并打开应用，点击“开启通知采集”，在系统页面手动允许通知使用权。
2. 开启钉钉考勤相关消息通知，等待下一次真实打卡通知。
3. 在“设置 → 钉钉通知采集”检查消息，核对待确认记录。

仅钉钉内部显示的消息卡片不一定会发送系统通知。通知隐藏、未发送、日期推定条件不满足或后台连接受限时可能无法自动记录。应用不会将班次时间或通知送达时间当作实际打卡时间；历史已消失的消息无法恢复。无CSV导入导出。

数据和候选通知保存在本机，候选记录最多100条。正式合计不包含缺卡和未确认的预计工时。国家节假日不自动识别，请逐日调整规则。

## 可选企业接口

企业管理员开通考勤查询权限并部署 [配套服务](backend/server.py) 后，可在“设置 → 企业接口”同步。企业凭据仅保存在服务端。个人登录钉钉不等于取得企业考勤查询权限。

配置见 [部署说明](docs/SETUP.md) 和 [环境变量示例](backend/.env.example)。

## 开发

原生 Java，无运行时第三方依赖。可使用 Android Studio / Gradle 8.9、JDK 17、Android SDK 35 构建：

```sh
gradle :app:assembleDebug
```

未附Gradle Wrapper，需要本地安装Gradle或由Android Studio配置。也支持 [离线工具链构建脚本](build-local.sh)，设置 `ANDROID_LOCAL_TOOLS` 指向ECJ和Android构建工具目录。

本地安装包签名密钥不进入仓库。覆盖升级必须使用同一密钥。
